# 社区版安全与限制

## 部署边界

当前为SQLite单机、单应用实例。文件、进程内限流和调度没有统一的多实例协调；不能直接增加副本并宣称可靠扩容。迁移PostgreSQL、对象存储和集中任务系统需要迁移、对账和故障演练。

快捷部署有配置、启动、数据库校验和一致性备份/恢复测试；当前执行环境未完成Docker、Linux/macOS、真实SMTP、公网证书签发的实机验收。使用前执行[部署指南](self-hosting-guide.md)的目标环境检查。

备份保存在同机不能抵御磁盘丢失。快捷工具的tar.gz包含明文凭据，必须使用受控/加密存储和异机副本；SHA-256仅检查损坏，不认证未知来源备份。时间点恢复可能丢失备份后的数据。

## 权限与资料

服务端会话和组织成员关系授权，前端缓存不授权。开放多个课题组共用服务前，需要实际验证实验室、课题、私人会话和附件隔离。当前后台用户画像汇总仍存在跨实验室查询范围待处理项；修复和验收前不要开放相关跨实验室画像场景。

API凭据有加密存储，但旧明文兼容和历史凭据轮换需要单独检查。管理员MFA、持续依赖扫描、异机恢复和告警仍需按部署实际情况完成；不能把历史测试或某次构建通过视作零漏洞证明。

## AI与文件

模型回复、候选结构和自动记忆可能错误，不直接作为库存或实验事实。文档读取会截断，扫描PDF不自动成为可读全文；文件解析不是操作系统级隔离沙箱。长文件、图表和图片按使用指南处理。

诊断采集默认关闭完整内容，用户同意和显式授权限制访问。Trace不是隐藏思维链；脱敏不代表通用个人信息匿名化。不要将诊断导出公开。

## 业务限制

学院公共业务和负责人交接界面尚未交付；账号退休不自动移交未完成任务。旧补货入口关闭。上传限额受应用和网关共同约束，已有网关可能比应用更严格。

问题反馈向维护者提供脱敏复现信息，不提交密码、模型Key、Cookie、原始研究数据或私钥。
