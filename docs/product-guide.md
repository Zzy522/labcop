# Lab Copilot 功能与使用指南

基线：2026-09-25 已发布提交 `db42838`。本文描述现有功能，不包含未实施的原型方案。开发配置见[开发者指南](developer-guide.md)，部署与恢复见[运维手册](self-hosting-guide.md)。

## 1. 账号与角色

| 身份 | 权限与入口 |
| --- | --- |
| 平台管理员 PLATFORM_ADMIN | `/developer-login` → `/platform`；审批实验室、平台用户治理、维护和审计 |
| 实验室负责人 LAB_OWNER | 管理端业务及负责人审批权限 |
| 实验室管理员 LAB_ADMIN | `/admin`；试剂、设备、成员、巡检等业务管理 |
| 实验室成员 LAB_MEMBER | `/user`；本人任务、领用、预约、上传及获授权的课题协作 |
| 课题管理员 MANAGER | 仅在获授权课题内管理；不会因此变成实验室或平台管理员 |

公开注册不能自行创建平台管理员。学院相关模型保留在数据库中，不能据此认为学院公共业务页面已交付。服务端会话与成员关系决定权限，浏览器缓存不构成授权。

### 入驻流程

1. 在 `/register` 填写身份资料，完成图形验证码和邮箱验证。
2. 创建实验室申请由平台审批；通过后建立实验室与负责人关系。
3. 加入已有实验室申请由目标实验室负责人处理，平台管理员可兜底处理。
4. 在 `/application-status` 查看状态；通过审批后按角色进入工作台。

平台管理员账号通过受控初始化脚本创建，不能通过公开注册获得。登录遇到状态异常时先重新加载会话；不要修改浏览器本地 role 绕过界面。

## 2. 工作台与导航

| 功能 | 管理端 | 成员端 |
| --- | --- | --- |
| 工作台 | `/admin` 管理总览、`/admin/research` 科研总览 | `/user` 个人工作台 |
| 试剂 | `/admin/reagents`、`/admin/reagents/new` | `/user/alerts`、`/user/reagents/[id]` |
| 设备与预约 | `/admin/equipment` | `/user/equipment-apply` |
| 审批/申请 | `/admin/review`、`/admin/members/applications` | `/user/applications` |
| 巡检/资质 | `/admin/inspections`、`/admin/qualifications` | `/user/inspections` |
| 成员管理 | `/admin/members` | 由管理人员操作 |
| 课题/化合物 | `/admin/knowledge`、`/admin/compounds` | `/user/knowledge`、`/user/compounds` |
| AI 助手 | `/admin/assistant` | `/user/assistant` |
| API 配置 | `/admin/api-config` | `/user/api-config`，具体配置范围由权限决定 |
| 设置/通知 | `/admin/settings`、`/admin/announcements` | `/user/profile`、`/user/notifications` |

首次工作台提供分角色快速指引，可跳过；也可通过“新手指引”主动查看模块指引。进度通过 `OnboardingProgress` 持久化，引导不会代替用户提交业务。

## 3. 试剂、票据与库存

- 管理员维护名称、CAS、规格、单位和风险资料；普通编辑要求版本匹配，防止旧表单覆盖新数据。
- `/user/upload` 提供入库相关入口；票据先保存原件并进入 OCR 处理，识别结果经过确认后才进入后续业务。
- 领用和审批受实验室归属、库存及状态约束；不要在响应不确定时另建重复申请。
- 库存实物差异通过“盘点调整”处理，填写原因并产生库存流水；不能在普通编辑中直接改库存数字。
- 归档试剂保留原库存、流水和票据，在已归档列表可恢复。
- 旧“补货”功能当前关闭，接口返回不可用提示；不要将其误认为新手工入库或盘点流程。
- MSDS、SOP、票据等私有文件通过受鉴权的接口访问，不通过公共静态目录分享。

库存成功写入不等于已有异机恢复点，备份由团队按运维手册管理。

## 4. 设备、巡检与资质

设备模块包括资料、状态、预约、使用记录和资质约束；高风险审批、时段冲突等以服务端检查结果为准。巡检由管理人员派发，成员提交，管理人员审核并跟进问题。资质有授予、到期和状态控制。

遇到预约冲突或资格不足，应处理具体提示，不绕过页面直接调用 API。管理员身份也不等于可以访问其他实验室数据。

## 5. 科研课题与文档

课题使用真实数据库与 API，包含成员、阶段任务、甘特图、任务修改申请、文档版本/审核、周报、变更历史和备份快照。权限同时考虑实验室和课题角色。

- 管理员和课题管理员管理获授权课题；普通成员只能执行其权限内的协作。
- 文件原件、版本和修改记录用于追溯；聊天附件不是课题文档的替代入口。
- 周报标题至少 2 字；进展正文去除首尾空白后为 10–12000 字符，上传附件后仍需填写正文。
- 周报应用校验为最多 8 个附件、单个 15 MB、总计 50 MB，拒绝空文件和可执行脚本。但当前 Nginx 限制整个请求为 `12m`，线上可上传大小实际更小；遇到 413 应缩小/拆分附件，不能按应用上限判断服务器一定接受。此配置差异已列入待办。
- 进度、日期、审核状态是业务事实，AI 摘要不能自动替代负责人确认。

## 6. AI、图片与文档附件

文本助手可通过受控只读工具查询获授权信息，图片由配置好的 VLM 处理。文档可以拖拽或点击上传：

| 格式 | 当前读取范围 |
| --- | --- |
| DOCX | 正文和表格文字 |
| PPTX | 按幻灯片顺序读取文字，不读取备注和嵌入图片 |
| PDF | 文字层，最多 100 页；扫描件需 OCR 或页面截图 |
| TXT / MD / CSV | UTF-8 文本 |
| DOC / PPT | 先另存为 DOCX / PPTX |

每轮最多 3 个文档，单个不超过 10 MB。抽取最多 12 万字符，每份文档每轮给模型的文字最多前 12000 字符；长文件需要拆分，当前没有全文分块检索。图表、结构图和公式需按实际情况单独上传图片。

原件、哈希与抽取结果保存在按用户/实验室隔离的 `data/assistant-attachments/`。输入框移除附件不会删除原件；解析失败的原件也保留，当前没有独立的失败附件管理界面。已有课题历史文档没有自动补做全文抽取。

SMILES 可通过本地 RDKit 生成结构图。模型输出、结构图和自动记忆是辅助信息，不代表实验结果已验证。流式回复有片段保存，但异常时仍可能丢失最后一次保存后的片段。

## 7. 成员删除、停用与实验室归档

### 删除账号（保留资料）

- 状态改为 `RETIRED`，保留 User ID、历史作者、课题、文档、会话和流水。
- 释放原邮箱，撤销登录会话与相关令牌，组织身份停用；原邮箱重新注册生成新身份，不继承旧权限和私人会话。
- 不能删除自己、平台管理员或仍承担负责人身份的账号。当前没有负责人交接界面。
- LAB_ADMIN 只能处理其权限内普通成员；LAB_OWNER 可处理本实验室管理员。关联其他组织的账号需平台管理员处理。
- 历史责任人和待办不会自动交接，团队需要另行安排；私人资料不会因删除账号而公开。
- `RETIRED` 不是可通过恢复/审批重新激活的停用状态。

### 实验室状态

平台管理员可以停用、恢复或发起删除等待。首次删除进入 7 天等待期；最终处理采用归档，状态为 `DELETED`，保留业务数据和文件，可恢复。旧版本已经物理删除的数据不会因升级自动找回，只能核对历史备份。

## 8. 维护与问题反馈

应用维护和 Nginx 部署维护是两层机制。服务器更新期间页面可能统一显示维护说明，API 返回 503；预计结束时间到达不代表系统会自动开放。更新后刷新页面，让前端与新接口版本一致。

问题反馈提供时间、角色、页面、步骤和脱敏错误信息，不提供密码、API Key、Cookie 或真实研究原件。当前待验收事项见[安全边界与待办](security-and-limitations.md)。

## 9. 分子输入、问题反馈与运行诊断（2026-09-25 已发布）

在完整助手页或悬浮对话框，点击输入框旁的分子图标，在画布绘制结构，再点击「插入 SMILES」。结构会转换为标准 SMILES 并追加到当前问题，原文字保留。空画布、初始化失败、转换超时会显示提示；确认内容后再发送。该操作输入的是分子结构，SMILES 与 C2H6O 一类分子式不是同一种表示。

新版本回答下方提供分开的「有帮助」「没帮助」按钮和「复制问题编号」。点踩立即记录，类型/说明与共享内容均可选。关闭补充弹窗不会取消点踩。问题编号格式为 LC-运行ID，可直接交给开发者定位；编号不是访问凭证。普通用户和实验室管理员不能查看或导出 Trace，直接访问旧接口也会被拒绝。

开发者进入 `/platform`：账号、实验室管理支持搜索和状态筛选，并可直接跳到其运行记录。「会话与 Trace」按问题编号、会话 ID、用户 ID、案例 ID、实验室、版本、状态或慢请求检索；从运行详情可查看已采集的对话轮次、阶段时间线、首字耗时和工具结果，按权限导出 JSON，或主动标记 Bad case。案例可填写负责人、原因分析、预期和断言，并保存候选结果验证历史。

Trace 是执行日志，不是模型隐藏思维链。当前记录主对话链路及上下文摘要阶段，后台独立的实体提取/画像任务不包含在这条回答 Trace 内。图片仅保留数量/文件名/哈希，复现视觉问题需要另行准备获授权的原图；文档摘录和工具输出若截断，会显式记录截断信息。

### 9.1 测试采集与授权

「诊断设置」可按实验室开启测试采集，确认已告知成员，设置未来 90 天内的结束时间和 1–90 天的内容保留期。默认关闭完整采集，只记录运行指标。开启后对话界面显示提示；关闭或到期仅影响新运行，不会补录未采集历史，也不会追溯改变旧运行的保留期。

运行检索、正文查看和导出分别授权，并可限制实验室。已有有效平台管理员在升级时获得显式诊断授权以保留运维能力；以后新增开发者需另行配置。平台管理员本身具有配置授权和采集策略的治理权限。普通实验室管理员不具有这些权限。

内容过期后即时禁止访问，后台每 10 分钟分批清理诊断正文和案例验证内容；删除会话也立即禁止访问并触发后续清理。用户的正常聊天历史仍按原业务规则保存。导出为单条运行或每页最多 50 轮会话，响应包含后续分页游标；不是无限制整库下载。


## 助手体验优化（本地未发布）

提交成功后，可切换业务页面、其他会话或刷新页面；返回原会话会显示最新生成进度。正在生成的会话暂不能追加问题，可新建会话继续使用，也可点击停止。断网不等于取消任务，请先查看原会话再决定是否重新提交。服务器重启、模型失败或超时仍可能终止生成，系统保留已有内容并标记未完成。

助手的 `smiles` 结构块会显示二维结构卡片，点击图片放大，可复制原始 SMILES。旧的本地结构图片链接也使用结构卡片。加载失败会显示实际错误和重试入口；生成的候选分子不等同于经过实验确认的化合物。

浮动助手可通过鼠标或触屏拖到左右边缘吸附，悬停或键盘聚焦展开按钮，点击打开。面板可拖动并保持完整位于窗口内。
