# Lab Copilot 使用指南（线上实拍）

面向课题组负责人、实验室管理员和实验员。截图于 **2026-10-06** 在 [labcopai.com](https://labcopai.com) 的管理员端和实验员端直接拍摄，使用实例已有演示数据。邮箱、手机号和模型配置已遮挡；录入、预约和周报示例均为**未提交草稿**。空列表表示拍摄时没有对应记录。截图中的测试数据、数量和单位不应作为实际实验或库存依据。

自行部署的实例拥有自己的网址、账号和数据，不会自动包含线上演示数据；本指南不提供演示账号密码。部署方法见[新手部署指南](self-hosting-guide.md)。全部原图及拍摄来源见[截图索引](screenshots/online-20261006/README.md)。

## 1. 功能与角色

| 模块 | 主要功能 | 使用者 |
| --- | --- | --- |
| 工作台 | 待办、管理和科研进展 | 管理员、实验员 |
| 化合物 | 名称/CAS/结构查询、录入、合成、活性、使用与表征资料 | 按账号权限 |
| 课题协作 | 研究目标、任务、甘特图、周报、文档版本与成员授权 | 课题管理员、成员 |
| 试剂库存 | 入库、领用、盘点、流水、归档与票据 | 管理员、实验员 |
| 设备 | 设备资料、状态、时段预约与审批 | 管理员、实验员 |
| 实验室管理 | 成员申请、审批、巡检、资质、报表与规则 | 管理员；成员处理自己的事项 |
| AI助手 | 授权业务问答、科研问答、图片/文档分析和分子输入 | 登录用户 |

实验室管理员管理本实验室；课题管理员管理获授权课题；实验员访问自己的申请和获授权资源。选择登录身份不会提升服务器权限。平台管理员另从 `/developer-login` 进入，负责实验室审批、平台治理与维护。本指南使用的业务账号没有平台管理权限，因此不混入模拟的平台截图。

新课题组建议按“负责人入驻 → 成员加入 → 配置试剂、设备与资质 → 建立课题 → 试运行领用与预约”的顺序开始。

### 4.2 绘制结构查询

1. 点击“化学式绘制查询”。这里查询的是**分子结构**，不是只输入 `C9H8O4` 这样的分子式。
2. 等待绘图器加载，用键、原子和环模板绘制。也可以在右侧粘贴 SMILES，点击“加载到画布”核对。
3. 在画布修改后，点击“从画布获取”同步右侧 SMILES，避免仍使用修改前的输入查询。
4. “精准查找”匹配相同结构；“子结构查找”寻找包含该结构片段的化合物。
5. 点击“查询”，查看结果；调整或清除结构条件后可重新检索。

下面使用 `c1ccccc1` 加载苯环，选择子结构匹配，并展示线上结果。

![Ketcher 绘图查询：加载苯环并选择子结构匹配](screenshots/online-20261006/27-structure-drawing.png)

*Ketcher 绘图查询：加载苯环并选择子结构匹配*

![苯环子结构查询返回的线上化合物](screenshots/online-20261006/28-structure-results.png)

*苯环子结构查询返回的线上化合物*

结构查询针对当前有权访问的库内记录；没有结果不等于物质不存在。检查 SMILES、匹配模式和其他筛选条件。没有结构的记录可改用名称或 CAS 查找。

## 5. 录入组内化合物与实验记录

### 5.1 新建化合物

点击“新建化合物”，依次填写：

1. **名称/内部编号、通用名、CAS**：内部编号用于组内追溯，没有 CAS 时不猜填。
2. **SMILES**：输入或用“绘制分子结构”导入，再点击自动计算分子式和分子量并核对。
3. **来源、关联课题和方法摘要**：关联课题是必填项；引用课题附件时写明可追溯的附件名。
4. **入库存量、单位、纯度和位置**：区分 mg/g、mL/L；确认后点击“创建”。日期和入库人由系统记录。

创建成功后，化合物会出现在所选课题中，并建立关联试剂。先刷新列表/详情确认结果，再继续添加实验记录。截图中的 `GUIDE-001` 只是未提交示例。

## 7. 周报文档与权限

### 7.1 提交与查看周报

课题内点击“提交周报”，填写周起始日期、标题、本周进展、阻塞事项、下周计划，选择附件后点击“提交并备份”。标题为 2–120 字符，进展正文为 10–12000 字符，上传附件不能替代正文。

![提交课题周报：正文、阻塞、计划与附件（未提交草稿）](screenshots/online-20261006/40-weekly-report-form.png)

*提交课题周报：正文、阻塞、计划与附件（未提交草稿）*

应用最多 8 个附件，单个 15MB、总计 50MB。**本次线上 Nginx 的整个请求上限为 12MB**；新快捷部署入口和学校网关可能不同。遇到 413 时压缩/拆分文件，或联系管理员确认入口限制。

在“课题周报”查看正文、提交时间、附件和备份标识。成员提交统计按课题成员核对，因此管理员本人提交不一定改变成员完成数。

## 9. 设备预约

管理员在“设备管理”维护名称、型号、位置、风险、状态与必要资质。停用或维护中的设备暂不能正常新增预约。

![设备管理](screenshots/online-20261006/10-equipment.png)

*设备管理*

实验员进入“设备预约”，筛选后点击“查看并预约”。“当前占用情况”和“我的预约”分别展示；现在被占用不代表未来没有空闲时段。选择不冲突的起止时间、填写用途后提交，高风险设备按规则审批，资质不足时联系管理员。

### 12.2 附件与分子输入

附件按钮支持图片和文档。文档每轮最多 3 个、单个 10MB，支持 DOCX、PPTX、带文字层 PDF 与 UTF-8 TXT/MD/CSV；旧 DOC/PPT 先转换。扫描 PDF 需要 OCR 或页面图片，长文档可能截断。附件和上下文可能发送给配置的模型服务，遵守课题组数据管理要求。

## 13. 常见问题与帮助

| 情况 | 先做什么 |
| --- | --- |
| 登录失败或审批后进不去 | 检查角色入口、邮箱和审批状态，重新登录或重置密码 |
| 没有课题或编辑按钮 | 请课题管理员确认成员和管理权限 |
| 绘图器一直加载 | 检查网络、刷新；自部署确认 Ketcher/RDKit 静态资源可访问 |
| 结构查询无结果 | 检查 SMILES、模式、其他条件，以及记录是否已录入结构 |
| 上传报 413 | 减少文件大小，请管理员检查代理入口限制 |
| OCR/AI 失败 | 检查服务配置和错误提示，日常业务可先手工处理 |
| 提交后状态不明 | 刷新记录确认是否已成功，避免重复提交 |
| 维护页面或 503 | 等管理员更新验收后刷新 |
| 库存数量异常 | 核对规格、单位与流水，再按盘点流程处理 |

报障提供角色、页面、时间、操作步骤和脱敏截图；AI 问题可附问题编号。不要将密码、Key、Cookie、真实课题原件或诊断正文发到公开 Issue。
